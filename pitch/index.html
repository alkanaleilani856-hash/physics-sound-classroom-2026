为什么有的声音
高，有的声音低？

这节课只抓住一条主线：振动越快 → 频率越高 → 音调越高。通过听声音、看波形、调琴弦和玩瓶子实验，把笔记里跳过的逻辑全部补上。

Chapter 01

频率：给“振动快慢”一个数字

频率表示物体每秒振动的次数，符号常用 f，单位是赫兹，简称赫，用 Hz 表示。

300 Hz
当前频率：300 Hz
每秒振动 300 次，音调较低
频率 = 振动次数 ÷ 时间
f = N ÷ t
300 Hz 是什么意思？

物体每秒振动 300 次。

600 Hz 呢？

每秒振动 600 次，比 300 Hz 振动更快，所以音调更高。

第一大易错点：音调高低由频率决定，不是由声音大小决定。声音高不等于声音响。
Chapter 02

怎样从波形图判断音调？

先确认横轴表示的时间范围相同，再数完整波形的个数。相同时间内，波形越密、周期个数越多，频率越高，音调越高。

波形 B

判断口诀：同时间、数波数；波越密，音调越高。波形的“高矮”表示振幅大小，主要影响响度，不用来判断音调。
Chapter 03

弦乐器为什么能调音？

研究一个因素时，要让另外两个因素保持相同，这叫控制变量法。同种材料的弦，一般越短、越紧、越细，音调越高。

三组控制变量实验

只比较粗细长度、松紧相同：弦越细 → 振动越快 → 音调越高。
只比较松紧长度、粗细相同：弦越紧 → 振动越快 → 音调越高。
只比较长度松紧、粗细相同：弦越短 → 振动越快 → 音调越高。
记忆方法：想让弦乐器音调升高，就把参与振动的弦变得“短、紧、细”。吉他按住不同品格，就是在改变弦的有效长度。
Chapter 04

敲瓶子和吹瓶口，结论为什么相反？

先找发声体。敲击时主要看瓶子和水组成的振动系统；吹瓶口时主要看瓶内空气柱。发声体不同，水量变化造成的结果就不同。

空气柱
50%
敲瓶子：水越少，音调越高
敲瓶子
水越多，系统越难振动，频率降低；所以水越少，音调越高。
吹瓶口
水越多，空气柱越短，振动越快；所以水越多，音调越高。
做题第一步：不要看到“瓶子和水”就背答案，先判断题目是“敲”还是“吹”，再确定谁在振动。

笔记中已经写出的主线

  1. 音调表示声音的高低，与物体振动快慢有关。
  2. 频率是物体每秒振动的次数，单位是 Hz。
  3. 人耳听觉范围约为 20 Hz～20 000 Hz。
  4. 相同时间内波形越密，音调越高。
  5. 弦越短、越紧、越细，音调越高。
  6. 敲瓶和吹瓶时，水量对音调的影响方向不同。

本课堂重点补全

  • 补出“相同时间内，完整波形个数越多 → 频率越高 → 音调越高”。
  • 强调波形高矮对应振幅，不要与音调混淆。
  • 解释控制变量法为什么必须一次只改变一个条件。
  • 补出敲瓶与吹瓶发声体不同，因此结论相反。
